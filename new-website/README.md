# Bhilwara Milk - Modern Website

A modern, responsive website for Bhilwara Milk dairy products, built with clean HTML5, CSS3, and JavaScript.

## Features

- **Modern Design**: Clean, professional layout inspired by the Adobe XD design
- **Responsive**: Works perfectly on desktop, tablet, and mobile devices
- **Fast Loading**: Optimized images and minimal code for quick load times
- **Interactive**: Smooth animations and hover effects
- **Contact Form**: Working PHP contact form integration
- **SEO Friendly**: Proper HTML structure and meta tags

## Structure

```
new-website/
├── index.html          # Main homepage
├── mycontact.php       # Contact form handler
├── assets/
│   ├── css/
│   │   └── style.css   # Main stylesheet
│   ├── js/
│   │   └── script.js   # Interactive functionality
│   └── images/         # All product images and assets
├── favicon.ico         # Website icon
└── manifest.json       # Web app manifest
```

## Sections

1. **Hero Section**: Eye-catching banner with product showcase
2. **About Section**: Information about quality and processes
3. **Our Pledge**: Company commitments and values
4. **Products**: Showcase of ghee products with pricing
5. **Quality Control**: Information about quality monitoring
6. **Contact**: Contact form and company information
7. **Footer**: Links and company details

## Setup

1. Upload all files to your web server
2. Ensure PHP is enabled for the contact form
3. Update email settings in `mycontact.php` if needed
4. The website is ready to use!

## Customization

- Update product images in `assets/images/`
- Modify colors in `assets/css/style.css`
- Update contact information in `index.html`
- Customize the contact form in `mycontact.php`
